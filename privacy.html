개인정보처리방침

슬리터 근무 (Sliter Work) · 시행일 2026년 11월 24일

1. 모으는 정보

이 앱은 개발자의 서버로 어떤 정보도 보내지 않습니다. 개발자가 운영하는 서버가 없습니다. 근무 선택, 근무편성표, 전화번호, 설정은 사용자의 기기 안에만 저장됩니다.

2. Google 사용자 데이터

  • 접근하는 범위: 사용자가 Google 로그인으로 허용한 경우에만, Google 캘린더의 일정(제목·날짜·색·메모)을 읽고, 만들고, 고치고, 지웁니다.
  • 쓰는 목적: 앱에서 고른 근무를 사용자의 캘린더에 반영하고, 캘린더에 적힌 근무를 앱으로 가져오기 위해서만 씁니다.
  • 저장: 읽어 온 근무는 사용자의 기기 안에만 저장됩니다. 로그인 유지 정보는 기기의 키체인에 저장됩니다.
  • 공유: Google 사용자 데이터를 개발자나 다른 사람·회사에 보내거나 팔지 않습니다. 광고에 쓰지 않습니다.
  • 그만두기: 앱 설정에서 로그아웃하면 로그인 유지 정보가 지워집니다. Google 계정의 「보안 → 계정에 액세스할 수 있는 서드 파티 앱」에서도 언제든 권한을 거둘 수 있습니다.

이 앱이 Google API에서 받은 정보를 쓰고 다른 앱으로 옮기는 방식은 Google API 서비스 사용자 데이터 정책(제한된 사용 요건 포함)을 따릅니다.

3. 사진과 연락처

  • 근무표 사진: 사용자가 「근무표 올리기」를 직접 누른 경우에만, 고른 사진 한 장이 글자를 읽기 위해 Anthropic의 API로 보내집니다. 이때 쓰는 API 키는 사용자가 직접 넣은 것이며 기기의 키체인에만 저장됩니다.
  • 연락처: 사용자가 「연락처에서 찾기」를 누른 경우에만 기기 안에서 이름이 같은 연락처의 전화번호를 찾습니다. 연락처는 기기 밖으로 나가지 않습니다.
  • 캘린더(기기): 사용자가 켠 경우에만 기기의 캘린더에 근무 시간표 일정을 넣고 고칩니다.

4. 지우기

앱을 지우면 기기에 저장된 모든 정보가 함께 지워집니다.
